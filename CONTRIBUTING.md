# Contributing

> **Placeholder.** This document is a stub and will be expanded before the first release.

sdlc-agent is in the planning / pre-alpha stage, so code contributions are not being accepted yet. Feedback on the design is welcome.

## How to help right now

- Open an issue for questions, ideas or problems with the plan in [`BUILD_PLAN.md`](./BUILD_PLAN.md).
- Check the scope (§2 of the plan) first: features outside it will not be accepted into v1.

## Ground rules (for when contributions open)

- Use npm and Turborepo only (no pnpm or yarn).
- Keep functions small and named after what they do; prefer boring, well-documented libraries.
- Do not add `Co-Authored-By` trailers or any AI attribution to commits.
- Never commit secrets, tokens or `.env` files.

By participating, you agree to follow the [Code of Conduct](./CODE_OF_CONDUCT.md).
