# Code of Conduct

> **Placeholder.** This document is a stub. It will be replaced with the full [Contributor Covenant](https://www.contributor-covenant.org/) before the first release.

We want this project to be a respectful, harassment-free space for everyone.

## Expected behaviour

- Be respectful and constructive.
- Assume good faith and welcome different viewpoints and experience levels.
- Give and accept feedback gracefully.

## Unacceptable behaviour

- Harassment, discrimination, personal attacks or insults.
- Publishing others' private information.
- Spam or other disruptive behaviour.

## Reporting

Report concerns by opening a private report through the repository's **Security** tab (**Report a vulnerability**) and marking it as a conduct issue, until a dedicated contact is published here.
